# 第一階段固定驗收規則（金融資料與模型）
**階段狀態：BLOCK／不可發布。** 不以通過單元測試或增加研究檔數取代金融有效性。

## 已證實
- 現存 54h 僅為 2026 股票快照母體，1977 檔，其中上市 1084、上櫃 893；缺歷史下市名單及公司行動完整追蹤。
- 54h 的 2017–2026 大跌研究可重現，但屬現存股票研究樣本，不能宣稱全市場歷史大跌機率。
- 原模型當月分位選樣會參考當月結果是否存在，已以 past_only_cohort.py 改成「只依前12個連續月份排風險，缺標記者仍列樣本」。2025 Brier 從原版本 0.0988494 至修正 0.0988508，差異極小但避免未來資訊。
- 本地容器無法解析外部網域，無法在本機直接下載交易所資料。
- 有 TWSE 與 TPEx 的指定歷史日期官方來源；已提交 read-only GitHub Action 進行四個日期／市場組合的來源連線測試，**Actions 實際成功仍未取得證據**。

## 固定七項必過驗收條件
1. 上市＋上櫃歷史證據（交易日、來源、原始 bytes SHA-256），來源缺漏要有覆蓋率。
2. 股票歷史母體含下市、轉板、改代號及回收事件；對帳且不可自行認定下市=歸零。
3. 股利、除權除息、減資、拆併與歷史報酬的核對。
4. 回測嚴格僅使用決策日之前確實可得資料，訓練／驗證／真正未用測試期間分開。
5. 大跌事件個別機率的校準與不同時期偏差檢測，不能混用波動率或往下延伸成十年虧損率。
6. 共同下跌／投資組合尾部／十年風險有適當的模型、數據與不確定區間。
7. App 端到端回歸與真正阻擋未核准模型發布；正式 GAS 與真實持倉不變，直到另行通過發佈驗收。

全部過關才 Stage1 PASS；其中任何一項不可由測試數量或未證實的預測品質替代。

## 工作原則
不跳關、不自行放寬原有專業模型需求；也不得將基於存活者母體的模型輸出標成官方驗證風險等級。
