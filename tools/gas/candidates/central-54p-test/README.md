# 54p：評估範圍顯示修正（僅測試版）

針對使用者在54o測試版看見首頁全部變資料不足的回報：

- 有未評級收藏品時，首頁改呈現「已有結果的資產分析」，列出已有模型結果的房產／金融資產等各自等級、金額與評估範圍。
- 不產生新的部分資產綜合等級或把部分結果當全部資產評級。仍有資料限制的舊模型不被宣稱新通過研究驗證。
- 未評估項目另列；缺資料或尚未建模不等同CCC／零風險。
- 覆蓋率分母保留總資產；小額金融資產沿用既有排除評級規則但不從分母消失。少量缺資料也不會四捨五入顯示100%覆蓋。
- 缺金融回測時仍呈現其他資產分析；保留既有歷史回測圖表及其資料限制說明。
- 核心僅變更54o→54p版本標記。沒有改動評級門檻、預期損失模型、房產參數、原現金策略或真實持倉。

22項既有App測試及10項新評估範圍／渲染檢查通過。渲染檢查使用完整App的實際函式與匿名fixtures，不是實際GAS或手機端驗證。嘗試用本機Chromium截圖遇執行環境問題逾時，未取得截圖，不宣稱手機視覺驗收通過。

下載App.html及核心.gs，透過管理後台「上傳到測試版」更新，再開/dev確認版本54p。中央.gs、appsscript.json及後台程式不變。不要按正式發布、除錯發布或執行approveTestRelease。

本版不是球員卡十項指標模型、自動查價或完整研究回測的交付成果；那些工作仍未完成，需要實際可核實成交與研究資料。
