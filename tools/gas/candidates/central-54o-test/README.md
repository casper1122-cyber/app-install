# 中央54o測試候選檔（未部署）

基於使用者提供的目前54n App及核心。保留54n地段、土地持分與其他房產計算；核心只有LIB_VERSION_從54n改54o，其他邏輯原樣。檔案指紋見manifest.json（此檔不是GAS的appsscript.json，不要上傳）。

候選修改：無逐項實證資料的收藏品不再用類別固定參數產生CCC／十年損失，改為資料不足；同步修正覆蓋率、綜合頁、首頁、未知風險及月度歷史；回測缺資料不再靜默刪除標的或把null當零；配置試算失敗顯示缺項並清掉舊結果；無效年齡防護。22項離線App檢查通過，14項後台安全檢查通過。尚未取得真實逐卡成交資料，沒有宣稱完成預測模型或市場樣本外效能。保留原現金策略，未對使用者50%現金現象宣稱找到根因。

先確保後台已是2026.10.26a，使用後台「部署」頁的「上傳到測試版」，只選App.html及核心.gs，檢查目標分別對應App與核心。不要選「除錯發布」「立刻發布」或執行approveTestRelease。中央.gs和appsscript.json保持現有版本，不需重傳。

測試用/dev開啟後確認版本54o：
- 球員卡應顯示資料不足而非固定CCC；價值、成本、清單仍保留。含未評級收藏品時總評應顯示不足及覆蓋率，不能出現Rnull或虛構0%損失。
- 逐一試算七個配置；核對圖表與數字。缺項時應看到原因，舊結果及儲存按鈕應清除。
- 用測試帳戶檢查推薦流程缺年齡是否詢問；核對現金拆分，不改真實帳務或重置既有持倉。
- 檢查既有房產頁及圖表仍能使用。

上傳只表示進測試版，並不代表功能驗收或正式發布。測試全部確認後才討論人工核准，不要現在執行核准。
