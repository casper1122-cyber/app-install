# 行政區房價季指數（re/hpid.json）怎麼重算

資料：桌面程式每天會把內政部實價登錄新的一季放到 rawdata/plvr/（2012 年 8 月起）。

1. load.py：讀 rawdata/plvr/*.csv.gz，只留住家用、一棟一戶（最多一個車位且車位價格拆得開）、排除親友／特殊關係／毛胚／瑕疵／凶宅／急買急賣／法拍／增建外推等，輸出成交資料。
2. idx.py：每個縣市做特徵價格迴歸（log 單價 ＝ 每一季 ＋ 行政區 ＋ 房型 ＋ 屋齡（含平方、30 年後另一段）＋ 坪數 ＋ 樓層位置），季係數就是縣市指數（再做 1-2-1 平滑）；
   每個行政區（300 筆以上）自己做一次，跟縣市的差距用筆數加權的 5 季移動平均，筆數少的往縣市縮（權重 n/(n+60)）；
   縣市內各房型（3000 筆以上）的走勢跟縣市比的倍數另存 type；屋齡係數存 age（App 用來算「房子一年一年變老」的折價）。
3. 驗證：縣市指數跟信義房價指數 2012Q3～2026Q2 比，長期走勢相關 0.96～0.99。

每季重算一次（內政部公布新一季後），把 re/hpid.json 換掉就好，App 不用更新。
