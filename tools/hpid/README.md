# 行政區房價季指數（re/hpid.json）怎麼重算、怎麼驗證

資料：桌面程式每天把內政部實價登錄新的一季放到 rawdata/plvr/（2012 年 8 月起，全台各縣市）。

1. load.py：只留住家用、一棟一戶（最多一個車位且車位價格拆得開），排除親友／特殊關係／毛胚／瑕疵／凶宅／急買急賣／法拍／增建外推等。
2. idx.py：每個縣市做特徵價格迴歸（log 單價 ＝ 每一季 ＋ 行政區 ＋ 房型 ＋ 屋齡 ＋ 坪數 ＋ 樓層位置），季係數就是縣市指數（1-2-1 平滑）；
   每個行政區（300 筆以上）自己做一次，跟縣市的差距用筆數加權的 5 季移動平均，筆數少的往縣市縮（權重 n/(n+60)）。

## 每次重算、或加入新的縣市／新的資料，一定要做這三種驗證（不能只看一種）
- 跟信義房價指數比（evalm 前）：縣市指數長期走勢相關要在 0.95 以上。（2026-10：0.96～0.99）
- rs.py / rs2.py：同一戶賣兩次的成交，實際漲幅 vs 算出來的。（2026-10：45,908 組，平均每年差 −0.04%）
- evalm.py：同一區、同年代、同房型的成交中位數，2013-14 vs 2025-26。（2026-10：278 組，平均每年差約 0.45%）
- 要加任何修正（屋齡、房型、世代…），兩種方法都要變好才加。2026-10 試過：屋齡係數、世代追蹤、重複交易校正，兩種方法說法不一致，所以都沒加。

每季重算一次，把 re/hpid.json 換掉就好，App 不用更新。
