安裝 App 到主畫面

照下面的步驟裝好後，主畫面就會出現 App 圖示。

現在是在 LINE／Facebook 裡面打開的，這裡裝不了。請按右上角「⋮」→「用其他瀏覽器開啟」（或「以 Chrome 開啟」），再回到這一頁。
Casper資產配置Android 版・圖示跟 iPhone 一樣
✅ 裝好了！回主畫面（或 App 清單）找寶寶圖示的「Casper資產配置」。

按了沒反應？自己加也可以

  1. 確定是用 Chrome 開這一頁（三星手機用「三星網際網路」也可以）
  2. 按右上角「⋮」（三星是右下角「≡」）
  3. 選「安裝應用程式」或「加到主畫面」→ 按「安裝」
  4. 回主畫面就有寶寶的圖示了

想要自己的名稱和圖示？

照片只存在你的手機裡，不會上傳。自訂的圖示右下角可能會多一個小小的 Chrome 標誌，這是 Android 對這種捷徑的標示。

第一次打開

  1. 登入你的 Google 帳號（被邀請的那一個）
  2. 看到「Google 尚未驗證這個應用程式」→ 點「進階」→「前往 資產配置 App（不安全）」；問權限時勾「全選」→「繼續」
  3. 新使用者按「建立新的資產配置」，跟著一步一步設定
  4. 設定好之後，把 App 整個關掉、再從主畫面開一次，就會變成全螢幕

第一次打開會先跳到 Google 登入，這時最上面有一小條網址列是正常的。登入、按過同意之後，把 App 關掉再從主畫面開一次，就會是全螢幕。如果之後還是一直有網址列，代表手機的 Chrome 擋了「第三方 Cookie」，App 一樣能用，只是多那一條。
出現「很抱歉，目前無法開啟這個檔案」？手機的 Chrome 同時登入好幾個 Google 帳號時會這樣。到 Chrome 右上角頭像，把預設帳號換成被邀請的那一個；或先登出其他帳號再開。
不想安裝也可以：直接用瀏覽器打開。
App 是邀請制，沒有被邀請的帳號打開只會看到「尚未受邀」。

現在不是用 Safari 打開的，裝不了（LINE、Messenger、Chrome 裡面按安裝，只會存成一個檔案）。
按右上角或右下角的「⋯」→「用 Safari 開啟」（Messenger 是「在外部瀏覽器開啟」），再按一次安裝。

用電腦開

💻電腦版直接在瀏覽器打開，可以加到書籤打開
出現「很抱歉，目前無法開啟這個檔案」？
這是因為瀏覽器同時登入了好幾個 Google 帳號，Google 會搞混。兩種解法選一個：
  1. 無痕視窗（最快）：按 Ctrl＋Shift＋N（Mac 是 ⌘＋Shift＋N）開無痕視窗 → 貼上這個網頁的網址 → 按「電腦版」→ 只登入要用的那一個 Google 帳號。
  2. 專用的 Chrome 使用者（之後最方便）：Chrome 右上角的頭像 →「新增」→ 用要用的那個 Google 帳號登入 → 在這個新視窗打開「電腦版」並加到書籤。以後點那個頭像就直接進去。

想像 App 一樣有自己的視窗和圖示：用 Chrome 開這一頁，網址列右邊會有一個「安裝」的小圖示（螢幕加向下箭頭），按下去就會多一個寶寶的捷徑。

想要自己的名稱和圖示？

自訂的安裝步驟（要多經過「檔案」App，iPhone 規定的）
  1. 按「產生並安裝」→ 跳出「儲存位置」時選「檔案」→ 按「儲存」
  2. 打開「檔案」App，到剛剛存的位置（通常是「下載項目」或「我的 iPhone」）
  3. 點 app.mobileconfig，畫面會說「已下載描述檔」
  4. 打開「設定」，最上面點「已下載描述檔」→ 安裝 → 輸入手機密碼 → 安裝
  5. 回主畫面，就會出現你取的名稱和照片

安裝步驟

  1. 點「安裝」→ 跳出提示時按「允許」
  2. 打開「設定」App，最上面會出現「已下載描述檔」，點進去
  3. 右上角「安裝」→ 輸入手機密碼 → 再按一次「安裝」
  4. 回到主畫面就有圖示了

第一次打開

  1. 登入你的 Google 帳號（被邀請的那一個）。主畫面的 App 跟 Safari 是分開的，第一次要登入一次，之後就不用了
  2. 看到「Google 尚未驗證這個應用程式」→ 點「進階」→「前往 資產配置 App（不安全）」；問權限時勾「全選」→「繼續」
  3. 新使用者按「建立新的資產配置」，跟著一步一步設定

這個描述檔只會在主畫面加一個網頁捷徑，不會改手機的其他設定；不要的話長按圖示移除，或到 設定 → 一般 → VPN 與裝置管理 刪掉。
